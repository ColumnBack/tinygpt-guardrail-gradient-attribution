# CLAUDE.md

Study repo (WIP): interpretability methods on a NumPy TinyGPT trained as an MCP tool selector,
used to find the tokens behind wrong decisions. GitHub: ColumnBack/tinygpt-interpretability,
Pages: https://columnback.github.io/tinygpt-interpretability/ (served from `main` `/docs`).

## Rules from the owner

- **Do not modify `tinygpt.py`.** It is the bundled base model (GCG-era copy of ColumnBack/tinygpt-numpy,
  with `forward_embedded`). Read its caches instead (`block_forward` → `Y`, `Z`, `Ocat`, `head_caches`).
- **Ask before any outward action** (git push, repo settings, Pages). Local edits are fine.
- **One model only: the 2-layer TinyGPT.** No 4-layer variant (decided to avoid confusion); its limits are
  documented in `docs/hidden_state_diff.md`.
- **Default score is the study's basic form `S = Z[<call>, y]`** (logit of the output token). `margin` and
  `logp` stay as optional variants only.
- Math notation follows `Interpretability math.pdf` and `docs/ig_formula.md`: X, X' (code: `Xp`),
  t = X' + α(X − X') (code: `t`, `alpha`), `g_t` = ∂S(t)/∂t, layer score D_ℓ, ℓ*, j*, ΔA.
- **Every number in docs/README/page must come from running the code.** Mark unverified explanations as hypotheses.
- Keep `README.md` (English, shown first) and `README.ko.md` (Korean) in sync.
- Scope is defensive/diagnostic; do not add attack techniques.

## Layout

| File | Role |
|---|---|
| `tool_data.py`, `train_tool_gpt.py` | 10-tool corpus; masked-CE training → `tool_model.npz` |
| `long_sentence_study.py` | long requests, one-noun edit audit (`audit`), `--augment` → `long_model*.npz` |
| `tool_attribution.py` | `score_and_grad`, `attribute` (|grad|, grad×input, IG, occlusion), `--check` |
| `occlusion_analysis.py` | zero / mean / delete, pairwise interactions, agreement with IG |
| `hidden_state_diff.py` | per-position diff, D_ℓ / ℓ*, ΔD_ℓ, logit lens, attention vs FFN change |
| `attention_analysis.py` | weight, norm-based contribution, rollout, j* and ΔA |
| `diagnose.py` | all methods on one flip + training data, verdict; `--all` agreement rates |
| `guardrail.py` | educational injection detector, same model and loss |
| `docs/*.md` | per-method notes; `docs/index.html` visual page (data embedded) |

## Commands

```bash
python train_tool_gpt.py --check        # gradcheck
python tool_attribution.py --check      # dS/dX finite-difference check (logit, margin, logp)
python long_sentence_study.py           # audit + IG walk-through (add --augment, --retrain)
python hidden_state_diff.py --summary
python attention_analysis.py --summary
python occlusion_analysis.py --summary
python diagnose.py --all
```
